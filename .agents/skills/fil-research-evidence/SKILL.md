# FIL Research Evidence
1. Separate observed fact, statistical inference, interpretation and hypothetical simulation.
2. For every candidate capture metrics, event IDs, population, role, match state, minute exposure and dataset/version.
3. Define alternatives (position role, team tactics, opponent, minutes, score state) and tests that could overturn the finding.
4. Require cross-match validation where claims generalize beyond one match; bootstrap samples at the correct unit and account for multiple comparisons.
5. For xT/VAEP, document model training set and holdout split, action definitions, coordinate transform and feature leakage prevention.
6. Return 'candidate_pending_review' or 'inconclusive' unless the evidence standard is met; never assert causal player impact from static node removal.
