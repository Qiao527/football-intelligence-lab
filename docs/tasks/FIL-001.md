# FIL-001 — Baseline repository and environment
**Goal:** Inspect current repo and build a minimal reproducible Python project baseline without breaking the existing v0.2 Notebook.
**Allowed:** project metadata, CI, dependency lock, README, tests skeleton, docs.
**Must deliver:** environment reproducibility, test commands, version report, source/current-feature inventory, file tree and blockers.
**Acceptance:** fresh install from lockfile; ruff/pytest (even if minimal) show actual exits; original experiment preserved; no fabricated demo data or metric values.
**Out of scope:** live sports scraping, AI Analyst, new frontend, metrics without data.
