# FIL-004 — Period-aware match clock
**Depends on:** FIL-003.
**Goal:** Represent provider period elapsed time, chronological match-play axis and display clock without losing stoppage, extra-time and shootout semantics.
**Deliver:** typed segment/filter model, conversion utilities, H1/H2 and extra-time edge tests, explicit estimates for absent Half End markers.
**Acceptance:** 45+2 H1 and H2 opening never collide; `period=5` excluded from match-play xG; window partition and boundary tests pass; no hard-coded `minute` only filter.
**Out of scope:** a complete app and unverified definitive video timecodes.
