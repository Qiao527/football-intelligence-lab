# FIL-000 — Read-only existing-repository audit (do first)

**Purpose:** Determine actual current implementation and avoid inventing missing features or rewriting working prototypes.

**Allowed:** inspect git branch/status/log, source tree, Python environment manifests, historical Notebook, existing tests and docs; run safe read-only inspection commands.

**Forbidden:** edit files, change branches, download restricted data, install dependencies, change CI, deploy, commit, merge, or infer facts from spec alone.

**Deliverables:**
1. repository name/branch/commit and detected current phase, with concrete evidence;
2. v0.2 Notebook evidence and whether `evidence_packet.json` was generated on this repo;
3. existing source manifests, schemas, metric definitions and test coverage;
4. issue-by-issue gap matrix for FIL-001–FIL-004 (DONE / PARTIAL / MISSING / UNVERIFIED);
5. one proposed smallest next PR, blockers and exact commands run.

**Acceptance:** every DONE finding points to a real file and successful check; no changes in `git status` caused by audit.
