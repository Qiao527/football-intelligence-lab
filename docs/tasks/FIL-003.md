# FIL-003 — Canonical event schema and source traceability
**Depends on:** FIL-002.
**Goal:** Convert immutable provider events to a typed canonical event table with event ID reverse lookup, source hash/version and no silent drops.
**Deliver:** mapper, Parquet output, schema and manifest, idempotent CLI, type/null and row-count quality reports.
**Acceptance:** raw count reconciles to processed count with documented exclusions, unique event IDs, events sampled can be retrieved by ID from raw JSON, fixture-based tests pass.
**Out of scope:** tactical conclusions, training xG, UI pages.
