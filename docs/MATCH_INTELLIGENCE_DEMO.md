# A 90-second internship demonstration

Use the default **fictional** mode. No protected provider records, names, screenshots or report
attachments are needed. Launch ahead of time with the README commands. This script describes
completed functionality; it is not a recording or a claim of human acceptance.

| Time | Action | Explain |
|---|---|---|
| 0–15s | Select Northbridge–Harbour; click Run match analysis | “FIL converts football events into a report whose claims can be checked.” |
| 15–30s | Show score, shared filters and charts | “The same selected records drive every foreground number. The full-match score stays fixed.” |
| 30–45s | Open a membership's original actions | “Every observation resolves to original IDs and untouched JSON. A verified fact is different from a useful tactical finding.” |
| 45–60s | Return to report; expand Counterevidence & interpretation limits | “The system exposes alternative explanations and all comparison Shots; deleting records is accounting, not causal simulation.” |
| 60–75s | Open Baseline & limits | “The complete conventional baseline can reproduce the facts. Analyst usefulness has not been independently established.” |
| 75–90s | Switch to Beacon–Westhaven, run, select Period 2 | “This empty chance selection abstains. The 64-match authorized research adapter uses the same engine with provenance gates; the public demo contains only fictional data.” |

The hardest implementation points: immutable pinned source validation, source-order scoring
including own goals and shootouts, missingness handling, precise claim scope and interactive
state/cache correctness. No language model is presented as the source of football evidence.

## Human acceptance checklist — not yet signed off

- [ ] Fresh checkout starts from the documented three commands without data or credentials.
- [ ] First-time user understands the product and fictional-data distinction within 60 seconds.
- [ ] A user can select/run all three matches, change period/team and reset filters.
- [ ] Every displayed observation can be traced to original actions and comparison Shots.
- [ ] The distinction between a fact, repeated pattern, hypothesis and general capability is clear.
- [ ] Source verification, empty selection, missingness and error states are understandable.
- [ ] Desktop and 390px mobile layouts are readable; original IDs can be inspected.
- [ ] The baseline and scientific limitations are discoverable without interpreting source code.
- [ ] Performance is acceptable on the intended laptop, using retained benchmark methodology.
- [ ] No one confuses deterministic computed output with validated autonomous AI discovery.

Automated browser checks are evidence for mechanics and layout, not a substitute for this review.
Independent expert football evaluation remains unrun. Public hosting, provider-data sharing and
historical PR integration require explicit authorization and their relevant checks.
